О проекте SignBridge

AI платформа двустороннего перевода жестового языка

🎯

Цель

Помочь в обучении и диалоге с помощью компьютерного зрения, наглядного словаря и проверяемого плана жестов.

🧠

Технологии

MediaPipe Hand Landmarker для ключевых точек руки, OpenCV для обработки кадров, необязательный scikit-learn классификатор и TTS.

🔄

Два рабочих сценария

→ Жест в текст: Находит демонстрационные жесты и буквы перед камерой, выводит текст и речь
→ Текст в жест: Строит план глосс и показывает его Canvas-аватаром

🌍

Языки

Планировщик принимает английский, русский и узбекский текст. Буквы распознаются в учебном наборе ASL.

📊

Архитектура

Python FastAPI API, WebSocket в реальном времени, MediaPipe, JavaScript, PWA и синтез речи.

🏫

Применение

Образование, здравоохранение и общественные места - везде, где нужна более доступная коммуникация для глухих и слабослышащих людей.

Технологический стек

MediaPipe

🚀 Масштабирование платформы

Векторы развития проекта для реального сектора

📱

Мобильное приложение

Упаковка платформы в кроссплатформенное мобильное приложение (React Native / Flutter), чтобы пользоваться учебным помощником прямо со смартфона.

🧑‍🎨

Реалистичный 3D Аватар

Замена текущего Canvas-рендера на полноценный WebGL/Three.js 3D-аватар с лицевыми анимациями (мимикой), так как эмоции - важнейшая часть грамматики жестового языка.

🧠

LLM Интеграция (ИИ)

Подключение ChatGPT/GigaChat для исправления синтаксиса. Жестовый язык имеет свой порядок слов (глоссы). LLM будет превращать "Я Магазин Идти" в красивое "Я иду в магазин".

☁️

B2B API & Облако

Предоставление API для интеграции SignBridge в банковские терминалы, кассы самообслуживания в международном ритейле и государственные веб-порталы в виде виджета.

🤖

Жестовый Ассистент (AI)

Создание умного помощника для глухих и слабослышащих людей. Ассистент сможет распознавать жестовые команды через веб-камеру, управлять умным домом и отвечать через визуального аватара.
