О проекте SignBridge

AI платформа двустороннего перевода жестового языка

🎯

Цель

Устранить коммуникационный барьер между глухонемыми людьми и остальным обществом с помощью ИИ и компьютерного зрения.

🧠

Технологии

MediaPipe Holistic для детекции скелета руки, RandomForest/LSTM для классификации жестов, TTS для синтеза речи.

🔄

Двусторонний перевод

→ Жест в текст: Распознаёт жесты глухонемого и переводит в текст/речь
→ Текст в жест: Переводит речь/текст в жесты через 3D аватар

🌍

Языки

Поддержка ASL (американский жестовый язык), английского, русского и узбекского языков вывода.

📊

Архитектура

Python FastAPI backend + WebSocket real-time + MediaPipe CV + JS/HTML5 frontend + TTS синтез

🏫

Применение

Образование, здравоохранение, общественные места — везде где нужна коммуникация с глухонемыми людьми.

Технологический стек

Python 3.11
MediaPipe
TensorFlow
Scikit-learn
FastAPI
WebSocket
OpenCV
gTTS

🚀 Масштабирование платформы

Векторы развития проекта для реального сектора

📱

Мобильное приложение

Упаковка платформы в кроссплатформенное мобильное приложение (React Native / Flutter) для того, чтобы глухонемой человек мог пользоваться переводчиком прямо со смартфона на улице или в магазине.

🧑‍🎨

Реалистичный 3D Аватар

Замена текущего Canvas-рендера на полноценный WebGL/Three.js 3D-аватар с лицевыми анимациями (мимикой), так как эмоции — важнейшая часть грамматики жестового языка.

🧠

LLM Интеграция (ИИ)

Подключение ChatGPT/GigaChat для исправления синтаксиса. Жестовый язык имеет свой порядок слов (глоссы). LLM будет превращать "Я Магазин Идти" в красивое "Я иду в магазин".

☁️

B2B API & Облако

Предоставление API для интеграции SignBridge в банковские терминалы, кассы самообслуживания (KFC, Вкусно и Точка) и государственные сайты (Госуслуги) в виде виджета.

🤖

Жестовый Ассистент (AI)

Создание умного помощника (аналог Алисы или Siri) специально для глухонемых людей. Ассистент будет «видеть» жестовые команды через веб-камеру, управлять умным домом и отвечать на вопросы с помощью 3D-аватара.
